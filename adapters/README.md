# Platform Adapters

- `CLAUDE_CODE_ADAPTER.md`: Claude `.claude/skills`, `CLAUDE.md`, `hooks`, invocation, compaction.
- `CODEX_ADAPTER.md`: Codex `.agents/skills`, `AGENTS.md` và optional `agents/openai.yaml`.
- `ANTIGRAVITY_ADAPTER.md`: AGY `.agents/skills`, `GEMINI.md`, `AGENTS.md`, rules.
- `CAPABILITY_MATRIX.md`: bản so sánh có nguồn và giới hạn.

Một adapter phải ghi rõ tên và phiên bản runtime/nguồn, tránh từ ngữ "all agents support" cho tính năng vendor-specific.
