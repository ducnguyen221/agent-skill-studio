Cài đặt

Cài theo cách hợp với agent của bạn

Yêu cầu: Python 3.9 trở lên, chỉ thư viện chuẩn, không cần pip install. Lệnh chạy tại gốc repo (trên Windows có thể gõ python thay python3).

Cách 1 — Cài như plugin

Gói plugin chỉ chứa thư mục skills/. Manifest nằm ở .claude-plugin/ (Claude Code) và .codex-plugin/ (Codex).

1

Claude Code

Gõ trong Claude Code:

Claude Code
/plugin marketplace add ducnguyen221/agent-skill-studio
/plugin install agent-skill-studio@agent-skill-studio
2

Codex

Repo có manifest .codex-plugin/plugin.json (tên agent-skill-studio, bản 0.2.0) nhưng lệnh cài plugin cho Codex chưa có trong repo. Dùng Cách 2.

3

Antigravity

Repo không có manifest plugin cho Antigravity; dùng Cách 2.

Chưa kiểm: lệnh /plugin marketplace add … chép từ README, chưa chạy thử trong lượt viết site này (cần mạng và Claude Code tương tác).

Cách 2 — Cài riêng một skill bằng studio.py install

install sao chép có kiểm tra, không ghi đè nếu thiếu --force. --workspace phải là thư mục có sẵn.

Terminal
# vào một dự án (thư mục khám phá của agent trong dự án)
python3 studio.py install skills/skill-creator-studio --agent claude --workspace .        # .claude/skills/
python3 studio.py install skills/skill-creator-studio --agent codex --workspace .         # .agents/skills/
python3 studio.py install skills/skill-creator-studio --agent antigravity --workspace .   # .agents/skills/
# cho cả tài khoản người dùng (Claude không hỗ trợ)
python3 studio.py install skills/skill-creator-studio --agent codex --user                # ~/.agents/skills/
python3 studio.py install skills/skill-creator-studio --agent antigravity --user          # ~/.gemini/config/skills/
Agent--workspace--userGọi skill
Claude Code.claude/skills/<tên>không hỗ trợ (thoát 2); tự chép vào ~/.claude/skills//skill-creator-studio
Codex.agents/skills/<tên>~/.agents/skills/<tên>; ~/.agents phải có sẵn$skill-creator-studio hoặc /skills
Antigravity.agents/skills/<tên>~/.gemini/config/skills/<tên> (App, IDE); ~/.gemini/config phải có sẵn; bản CLI dùng đích khác, install không ghi vào đótheo IDE/CLI, thường /skill-name

Lưu ý: Codex và Antigravity dùng chung .agents/skills/ trong dự án, nên cài một lần là cả hai thấy. Đừng cài cùng skill hai lần dưới hai tên khác nhau, vì chúng sẽ tranh nhau được gọi.

Cách 3 — Mẫu luật cho dự án khác

Chép templates/starter-project/ vào dự án đích: AGENTS.md là bộ luật chung duy nhất; CLAUDE.md nạp nó bằng dòng @AGENTS.md; Codex đọc thẳng AGENTS.md; GEMINI.md trỏ về AGENTS.md. Mỗi file có sẵn một dòng install đúng cờ.

Kiểm sau khi cài

Terminal
python3 studio.py --version                       # in 0.2.0
python3 studio.py doctor                          # quét skills/ của repo, chỉ báo cáo; thoát 0 sạch, 1 có phát hiện, 2 không quét được
python3 studio.py doctor --roots ".claude/skills" # quét gốc skill khác (ngoài repo bắt buộc --roots hoặc --roots-file)
python3 studio.py check skills/skill-creator-studio

Rồi kiểm trong agent: Claude Code tìm được /skill-creator-studio (và /context cho thấy CLAUDE.md đã nạp @AGENTS.md); Codex liệt kê /skills hoặc gọi $skill-creator-studio; Antigravity kiểm .agents/skills/ đã được nhận và tên skill hiện ra. Có thể hỏi agent: «Which repo instruction files and Skill names are active?».

Nâng cấp và gỡ

Nâng cấp

Bản cài bằng install: chạy lại với --force; bản cũ chuyển sang .skill-studio-backups/ (ngoài gốc skill), rồi bản mới thay vào. Đọc CHANGELOG.md mục 0.2.0 trước khi nâng từ 0.1.0 vì có đổi hợp đồng.

Gỡ

Bản cài bằng install là một thư mục thường dưới các đường ở bảng trên.

Chưa có trong repo: lệnh nâng cấp plugin (Claude Code, Codex) và lệnh gỡ (cho plugin hay cho bản install).

Giới hạn khi cài

Thư mục skill là symlink hoặc junction?

install thoát 2 (cờ --allow-root-link cho phép có chủ ý và in đích thật); đích là link thì thoát 1.

Trên macOS, new --output dưới /tmp bị từ chối?

Đúng: /tmp và /var là symlink. Dùng thư mục dưới $HOME.

Antigravity có đọc references/ không?

Chưa chạy thật để biết (not_run).
