Giới thiệu

Repo chuẩn mực để tạo skill

Mục tiêu: trở thành repo chuẩn mực để tạo skill cho Claude bản mới nhất và cho nhiều agent dùng chung.

Mục tiêu

Lộ trình đặt năm năng lực: luật nạp được cho ba agent; bộ dò, kiểm, doctor cho skill, quy trình và file luật; học từ hoạt động (đã chuyển sang OpcOS); phát hiện skill trùng để gộp, bỏ, đồng bộ; danh mục toàn hệ.

Định vị

Skill Factory của OpcOS

Cấp chuẩn viết, kiểm định và đóng gói skill cho các plugin khác. Sổ đăng ký OpcOS xếp Studio vào nhóm engineering, loại plugin, cài tuỳ chọn.

Ba harness

Claude Code, OpenAI Codex, Google Antigravity. Phần chung theo Agent Skills Specification; phần riêng ở standards/HARNESSES.md.

Ranh giới

Studio chỉ đề xuất. Báo cáo AUDIT không sửa skill; repo sở hữu skill tự cài và tự phát hành.

Engine ngoại tuyến

Không gọi Claude, Codex hay Antigravity. Đo bằng model thật chạy riêng theo evals/RUNBOOK.md.

Trạng thái 0.2.0 (phát hành 2026-10-28)

Đã có

  • Repo gọn còn 6 thư mục (nay thêm docs/ cho site).
  • Chuẩn từ 11 file gộp còn 8; thêm luật cho 3 loại tài liệu (DOC_TYPES.md).
  • CORE_RULES.md sinh tự động từ chuẩn, có test canh khớp.
  • Bằng chứng đo dời ra sổ riêng mà cổng vẫn đếm lại được.
  • Vá 5 lỗ an toàn nhỏ: không đọc file trong vùng cloud hay secret, không đi xuyên đường tắt, không ghi đè file eval.

Giới hạn

  • SC5 không đạt theo số: đo kích hoạt trên bản cài thật, bản mới 4/10 ca nên gọi, bản cũ đối chứng 5/10, cả hai 0/6 ca gọi nhầm.
  • model_evaluated: false cho skill-creator-studio; chưa có khối kết quả đo trong catalog.
  • data-quality-audit đo lô SPR-18 cho below-threshold (Claude Code và Codex đã chạy; Antigravity not_run).
  • Antigravity chưa đo được kích hoạt vì chế độ headless không sinh transcript.

Nghiệm thu: Đạt có điều kiện. Đức quyết phát hành và ghi «SC5 Đạt có điều kiện do Đức quyết»: dòng description của skill không đổi giữa hai bản, chỉ lệch 1 ca, lượt 2 hai bản bằng nhau. Điều kiện: chặng 3 làm thước đo nhạy hơn rồi đo lại.

Đổi hợp đồng so với 0.1.0: catalog dời sang evals/catalog.json; bằng chứng thành một file gọn mỗi lô; plugin chỉ phát hành 1 skill thay vì 2; new không ghi đè file eval đã có. Bảng đầy đủ ở CHANGELOG.md.

Mốc tiếp: 0.3.0 sau chặng 3 (doctor toàn hệ, danh mục, phát hiện trùng); 1.0.0 khi chặng 4 đo hiệu quả thật đạt ngưỡng.
