# Google Antigravity project notes

Read and follow `AGENTS.md` (shared rules). Use it as the source of common repo guidance; when this runtime also loads `GEMINI.md`, these notes are additional, not a duplicate copy of the common rules.

Project Skills live in `.agents/skills/<name>/SKILL.md`; install: `python studio.py install <skill> --agent antigravity --user` (the agent's config folder must already exist; `--workspace .` installs into the project instead). Per-directory rules may use `.agents/rules/` according to current official docs. Validate which files are active in the target IDE/CLI before deployment.
