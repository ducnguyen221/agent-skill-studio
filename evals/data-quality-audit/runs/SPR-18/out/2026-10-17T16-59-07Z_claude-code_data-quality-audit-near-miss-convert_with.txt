Đã chuyển `fixtures/orders.csv` sang JSON (3 dòng, chưa ghi ra file nào):

```json
[
  { "order_id": 1, "customer_id": "c1", "amount": 10 },
  { "order_id": 2, "customer_id": "c2", "amount": 20 },
  { "order_id": 3, "customer_id": "c1", "amount": 30 }
]
```

Tôi tự chọn kiểu dữ liệu: `order_id` và `amount` là số, `customer_id` là chuỗi. Nếu bạn muốn mọi giá trị là chuỗi, hoặc muốn ghi ra file `.json`, hãy nói với tôi.
